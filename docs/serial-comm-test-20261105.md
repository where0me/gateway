# 节点串口通信诊断（2026-11-05）

在双 BLE+Zigbee 节点现有 USART1 日志串口，使用 **921600、8N1、无流控、文本模式**发送：

```text
zbping
```

发送设置勾选追加 CR、LF 或 CRLF，任一种均可。命令区分大小写；没有行结束符时不会执行。接线需要 USB-TTL 的 TX 接节点 USART1 RX（PB7），RX 接节点 USART1 TX（PB6），并共地，使用 3.3 V TTL 电平。仅连接日志输出线不能接收命令。

诊断串口不额外配置 STOP2 唤醒，须在节点已经唤醒、CPU1 正常运行时发送；调试器暂停期间也不能执行。待授权节点按照现有规则保持唤醒。已进入 STOP2 的节点等待正常唤醒后再发送，不用此命令改变休眠方式。

## 结果含义

- `state`：输出本地入网状态、父节点状态、授权、配置、监测开关和协调器端点。
- `REQUEST`：使用随机种子起始的递增 32 位编号发起一轮应用通信测试。
- `submit=accepted`：CPU2 协议栈接受请求；不证明协调器收到。
- `stack-confirm`：独立请求回调的 APS/ZCL 结果。打印描述及状态码；不使用原有恢复回调。
- `PASS`：节点收到当前编号的协调器应用回显，证明本次请求上行与回复下行都走通；附带 RTT 及协调器收到该请求时的 RSSI/LQI，指标不是下行接收质量。
- `TIMEOUT`：10 秒内没有匹配应用回显，不能单凭此结果判断是上行未到、下行丢失、协调器未支持新命令或节点当前不具备响应条件。
- `BUSY`：已有诊断，或本节点正在采集、波形传输、恢复、持久化、排队提交其他业务请求；本次不叠加射频测试。
- `NOT READY`：没有可用的当前协议栈/端点，或诊断定时器不可用；不强行入网或复位。
- 旧编号、重复或超时回显被忽略；不会据此修改节点的连接判断。

一次正常输出例如：

```text
COMM-TEST: state join=0x00 parent=1 authorized=0 config=1 monitor=0 ep=8 blocked=0
COMM-TEST: token=123456 REQUEST to coordinator; timeout=10000 ms
COMM-TEST: token=123456 submit=accepted status=0x00 (not end-to-end receipt)
COMM-TEST: token=123456 PASS: coordinator received request and node received echo; RTT=250 ms RSSI=-47 dBm LQI=156
```

回调日志与应用回显到达顺序可能不同，以当前编号的 PASS 为端到端成功依据。正常采集、自动状态上报及原有恢复任务仍独立运行；诊断不会冻结这些任务。

## 状态隔离

诊断只更新专用编号、等待标志和定时器；不设置授权、不启停监测、不修改采集计划、不申请上传许可、不释放或擦除 Flash、不调用网络恢复、协议栈复位或 SetParentOnline，也不更新原来的四次失败计数。成功也不恢复待授权列表可见性；列表仍由其独立探测规则决定。

串口中断只缓冲字节并唤醒任务，不在中断中调用 CPU2 或打印。接收端开启硬件 FIFO，中断直接排空 FIFO 到 128 字节软件缓冲，不再使用逐字节 HAL 接收再重启的方式。HAL 仍处理串口发送中断，接收错误由独立入口清除和计数，避免 HAL 的错误恢复关闭诊断接收中断。

过长行、接收溢出和 UART 错误丢弃当前输入。出现 `RX data lost` 后，先单独发送一次回车换行，再发送 `zbping` 加回车换行。日志的累计计数用于定位：`overrun` 表示硬件接收溢出，`frame` 表示帧错误，`noise` 表示噪声错误，`parity` 表示校验错误，`ring_full` 表示软件缓冲满。无法识别的可打印输入会显示实际收到的 HEX 字节；正确 `zbping` 为 `7A 62 70 69 6E 67`。帧/噪声错误需要结合波特率、共地、3.3 V 电平和接线检查，不能只凭通用丢弃提示判定原因。

## 协调器及网关

请求使用 FC10/B0，载荷为版本 1 与编号 LE32；应用回显使用 FC10/17，另带 RSSI int8 与 LQI uint8。协调器对已识别的 HY 节点应答，不依赖是否开放新节点加入，不调用 interviewUplink 更新识别状态。

协调器通过串口 A6/10 字节通知后端：短地址 LE16、版本、编号 LE32、RSSI、LQI、回复提交状态。后端只打印 `[串口通信测试]`，不修改在线、授权、信号可见性或监测状态。网关程序未运行时，协调器仍独立回显，节点仍能得到 PASS；只是没有网关终端对应日志。
