# MQTT 设置与真实上传联通（2026-10-20）

此文档保留早期设计记录。当前仅支持Sparkplug B，设置页不再提供协议选择，旧主题前缀会在保存时移除。现行行为见 [Sparkplug B 数据上报](mqtt-sparkplug-20261027.md)。

## 部署与使用

本次同时更新 `gateway-core` 和 `gateway-ui`，无需重新烧录节点或协调器。
先停止旧后端，在 Linux `gateway-core` 目录 `make` 后启动 `./gateway-server`。
前端重新运行开发服务或部署 `npm run build` 生成的 `gateway-ui/dist`。
打开“设置 → MQTT 上传”，配置从后端当前运行目录的 `gateway_config.json` 加载，不使用前端样例地址。
与现有页面一致，前端请求当前页面所在主机的 8080 端口；浏览器必须能访问该主机上的后端。

- 上传开关、服务器地址/端口、用户名、密码、网关 ID。
- 高级配置：客户端 ID（留空自动生成）、心跳（5～3600 秒）、上传确认超时（1～300 秒）。
- “测试连接”启动真实、异步、独立客户端的 MQTT 3.1.1 连接测试。仅检测连接和认证，不发布数据、不中断正式上传，不写配置。账号按 Client ID 授权时须注意测试使用不同的临时 ID。
- “保存并应用”先验证配置与队列，原子写文件（Linux 0600 临时文件、文件同步后重命名），再关闭旧连接并采用新配置。文件写入失败时不改变当前运行配置。
- 上传状态每 3 秒更新，编辑中的表单不被自动刷新覆盖。连接状态来自已应用配置，而不是未保存的开关或测试结果。
- 不提供 TLS、自定义主题、主题前缀编辑、演示状态或固定统计。

## 密码与访问范围

设置查询及保存成功响应返回文件管理的 `password`，页面直接回填；保存或重新打开页面后密码仍在输入框中，默认隐藏，可用小眼睛切换明文。已移除“保存时清除现有密码”复选框；清空输入框再保存即可清除密码。
`GATEWAY_MQTT_USERNAME` / `GATEWAY_MQTT_PASSWORD` 覆盖时，页面禁用相应编辑，保存其他字段不会把环境变量密码抄入文件。
新接口拒绝重复/未知字段、错误类型、不支持的协议、无效端口和超范围配置。
密码仅在设置响应及提交的 JSON 请求体中传输，不进 URL、浏览器本地存储或日志。状态查询、连接测试结果和错误响应不返回密码；环境变量密码不回传给浏览器。
新接口使用 no-store，并限制跨域网页为与后端相同主机（允许不同端口及 localhost/127.0.0.1 的本机别名）；拒绝任意外站来源。写操作必须使用 application/json。

这没有为整个管理面增加账号认证。仍按现有可信局域网管理面使用，不应向公网直接开放 8080；MQTT 仍为明文 TCP。生产网络需另做管理面认证及传输保护。

## 队列与状态定义

- 待上传批次数：当前上传目标下尚未获全部 PUBACK 的持久队列记录数（按修订计数）。
- 待上传数据量：这些记录中未确认 JSON/波形的字节总数；已确认的部分不再计入。
- 最近上传确认：当前目标最后一个完整批次获全部 MQTT 确认的数据库时间，重启后仍可查询。它不是业务数据库入库确认。
- 未启用时不发送、不整理新队列，但节点采集和本地源数据继续保存；重新启用后补发。显示的队列统计不冒充尚未整理的全部源记录。
- 服务器 URL、用户名、网关 ID、既有主题前缀构成目的地。变更目的地保留旧队列，不把旧载荷误发到新目标；页面提示其他目标未确认记录。完整源数据会按新目标整理、历史补发。
- 密码、心跳、确认超时或 Client ID 改动不改变目的地身份，不新增重复快照。
- 旧连接回调不会覆盖新连接状态或确认新连接任务。超时/断线依旧重发未确认部分。
- 统计或后端不可用显示未知，不显示为零或成功。

## API

| 请求 | 用途 |
| --- | --- |
| `GET /api/mqtt/settings` | 可编辑配置（包含文件管理的密码）、配置是否有效、实际运行状态 |
| `POST /api/mqtt/settings` | 保存并热应用（保留串口和其他配置字段） |
| `GET /api/mqtt/status` | 运行状态与队列统计，不覆盖表单 |
| `POST /api/mqtt/test` | 启动独立连接测试，返回 202 与测试 ID |
| `GET /api/mqtt/test?id=…` | 查询该测试的 testing/success/failed 结果 |

写入字段：`enabled`、`url`、`gateway_id`、`client_id`、`username`、可选新 `password`/`clear_password`、`keepalive_sec`、`ack_timeout_ms`。
接口保持向后兼容：省略或传空 `password` 保留旧密码，`clear_password: true` 明确清除。页面会在用户清空已有密码时自动发送清除标志，不再需要复选框。
旧配置中的 `topic_prefix`、队列限额、连接超时及其他未知配置字段保留，不新增用户自定义主题接口。
文件被外部程序直接修改后仍需重启后端加载；网页保存则立即应用。
